# Incident Severity Matrix

| Severity | Definition | Response |
|---|---|---|
| SEV-1 | data loss, cross-tenant exposure, payment integrity or total outage | immediate page, incident commander, 30-minute updates |
| SEV-2 | material branch degradation or sustained SLO breach | on-call response, hourly updates |
| SEV-3 | isolated non-critical defect/workaround exists | next business-day response |
| SEV-4 | documentation/cosmetic issue | backlog |
