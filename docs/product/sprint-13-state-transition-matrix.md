# Sprint 13 state-transition matrix

Subscription: `DRAFT→TRIALING|ACTIVE`, `TRIALING→ACTIVE|GRACE|CANCELLED`, `ACTIVE→PAST_DUE|CANCEL_AT_PERIOD_END|CANCELLED`, `PAST_DUE→ACTIVE|GRACE`, `GRACE→ACTIVE|READ_ONLY`, `READ_ONLY→ACTIVE|SUSPENDED`, `SUSPENDED→ACTIVE|TERMINATION_PENDING`, `CANCEL_AT_PERIOD_END→ACTIVE|CANCELLED`, `CANCELLED→ACTIVE|TERMINATION_PENDING`, `TERMINATION_PENDING→ACTIVE|TERMINATED`.

Invoice: `DRAFT→OPEN|PAID(0)`, then `OPEN→PARTIALLY_PAID|PAID|PAST_DUE|VOID`. Payment: `REQUIRES_*→PROCESSING→SUCCEEDED|FAILED|UNKNOWN`; UNKNOWN resolves only through reconcile. Support: `REQUESTED→APPROVED|DENIED`, `APPROVED→ACTIVE|REVOKED|EXPIRED`, `ACTIVE→REVOKED|EXPIRED`.
